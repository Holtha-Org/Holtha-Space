# Aviso de atribución de `zeroth`

La carpeta `zeroth` contiene una copia independiente del código fuente de Rust,
incluyendo componentes del compilador, la biblioteca estándar y sus herramientas.

Los derechos de autor de ese código pertenecen a sus autores originales,
principalmente a los contribuyentes del Proyecto Rust. Rust se distribuye, salvo
que se indique lo contrario, bajo las licencias Apache 2.0 y MIT. El código de
terceros puede estar sujeto a licencias adicionales.

Los avisos completos se conservan dentro de `zeroth` en:

- `COPYRIGHT`
- `LICENSE-APACHE`
- `LICENSE-MIT`

independiente. Este aviso no sustituye las licencias ni los avisos de copyright
incluidos con el código.
