# Aviso de Licencia y Atribución — Herrat CLI

Este proyecto (`herrat`) utiliza componentes y arquitectura adaptados del gestor de paquetes Cargo (desarrollado por la Fundación Rust y sus colaboradores), bajo los términos de la Apache License, Version 2.0 y la MIT License.

## Reconocimiento de Origen
El núcleo de gestión de dependencias y CLI de Herrat fue iniciado tomando como base de bootstrap la arquitectura de Cargo, la cual ha sido modificada, renombrada y adaptada de forma totalmente independiente para integrarse nativamente con el lenguaje **Zeroth** y el asistente local **Somer**[cite: 1].
